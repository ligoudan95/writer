- 单写者原则结构性失效：同步批次线程第二 Library 实例持独立锁 → 按规范化库根全局注册写锁

- 回收站还原 orig_rel 无校验（穿越）→ 路径段校验 + 仅 docs/ + 同名不覆盖（还原 N）
- 同秒删除同名互覆、快照同秒 id 冲突、快照字数含 fm、快照回滚双 frontmatter（整文件覆盖）、rename title 控制字符注入、文件夹同名改名得"-2"、walk_dir 符号链接环、`atomic_write` 无 fsync（断电窗口）、last-library 裸写、锁外命名 TOCTOU（create/import/folder）

## 第二轮（对修复本身的复审）发现并修复

- 行内代码双反引号定界不充分（内容含 `` `` `` 即结构损坏）→ 最长游程+1 定界
- saveNow 保存期间被置 dirty 会遭"saving→saved"回写覆盖（接受草稿丢稿）→ dirty 保持 + 补一轮
- ai:cancelled 未按 jobId 门控（迟到取消复位新续写，整段消失）
- 润色取消不清 jobId + onPolishDone 无 state 守卫（取消复活 review、过期区间误替换）
- AiSettings 拉模型：新建 Provider 用空 id / save 关面板导致功能不可用 → saved.id + 保持面板
- 隐私拦截时用户输入被清空 → 按受理结果清输入
- 首绑 Download 方向附件未落状态行（首轮 bound 仍全量重传）
- propagate_local_deletes 按代跳过使"复活再删除"墓碑永失活 → 无条件幂等 upsert
- 改名跟随只对路径不对内容（标题永久分歧）→ 采纳远端内容 + external_change
- MOVE 失败两分支绕过门控（振荡/改名丢失）→ 旧路径保留判定 + uuid 验证式收敛清理
- 探测失败缓存空字节（远端文档被空壳覆盖的潜在链路，三轮发现）
