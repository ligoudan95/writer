## 修复内容

### bug①：冲突后「重新加载磁盘版本」不刷新编辑器（M1/M2 已知 bug）

- 根因：`openDoc` 重载同一文档时 `s.current.path` 不变，EditorPane 仅 watch path，内容不重应用；M3 的 `reloadNonce` 机制只在 `doc:external_change` 事件里递增。
- 修复（`src/store.ts`）：`openDoc` 检测同路径重载时递增 `reloadNonce`，复用 M3 的 nonce 驱动重应用（撤销栈语义与远端更新一致）。

### bug②：新建文档标题不递增（M1/M2 已知 bug）

- 根因：`unique_name` 文件名去重产出 `无标题-2.md`，但 frontmatter `title` 恒写 base，侧栏出现多个同名"无标题"。
- 修复（`src-tauri/src/library.rs`）：`unique_name` 改为返回 `(文件名, 序号)`；`create_doc` 标题随序号递增（FR-DOC-05 新建命名流：无标题 → 无标题 2 → 无标题 3）。`rename_doc_inner` 保持用户输入标题不变（序号仅作用于文件名，符合 FR-DOC-05"文件名 = 标题 + 重名加序号"）。
- 新增回归测试 `create_doc_title_increments_on_duplicates`（树显示名、文件名、frontmatter title 三方一致）。

## 缺口核查结论（定界到 M5 正式范围）

以下 P0 项确认为**里程碑级工程**，不在清账范围，列入 M5：

1. **单元格合并（FR-EDT-09）**：冻结方言（v1.1 定案：CommonMark + GFM 扩展）的管道表格无法表达 colspan/rowspan；单独加工具条按钮会造成 md 往返丢失合并结构（违背 md 权威数据源）。需先做方言扩展设计（候选：HTML 表格直写回退，类比 `<u>` 先例）再交付按钮与 codec 双向支持。
2. **DOCX 导入（FR-IMP-01）**：TXT/MD 已交付；DOCX→Markdown 方言转换（表格/列表/加粗斜体）待实现（Rust 侧 docx 解析 crate 选型 + codec 接线）。
3. **拖拽排序与移动（FR-DOC-02）**：含步长 10 编号、空档插入、防改名风暴局部重排、插入位置指示线、`N-标题` 前缀体系——与同步强耦合（序号经文件名同步），需整体设计。
4. **B4**（拖放文件导入、右键菜单入口）：附录 C 实现粒度项，随 M5 交互收尾统一落地。
