## 交付内容

### Rust 核心（src-tauri）

| 模块 | 内容 |
|---|---|
| `src/dav.rs` | StorageBackend 契约（5.1）+ reqwest WebDAV 实现（PROPFIND/GET/PUT/MOVE/DELETE/MKCOL、rustls、gzip、Overwrite:F）+ 前缀无关 PROPFIND 解析器 + 内存 MockDav（双机模拟替身） |
| `src/secrets.rs` | Secrets 服务（5.1/NFR-08）：DPAPI 加密凭据，密文存 %APPDATA%\Writer\secrets.json，永不入库 |
| `src/sync.rs` | 同步引擎：状态机批次（scanning→planning→executing→settling→idle）、逐文件事务性提交；uuid 身份锚点 + 内容 hash 权威 + etag 缺失回退下载比对；MOVE 改名传播；删除传播（墓碑 + 对端回收站 + 不复活）；冲突副本（新 uuid + conflict_of 标记 + 三动作）；双端改名冲突回退冲突副本；首次绑定方向（两端非空零写操作）；远端改名跟随；无 id 外部文件导入；远端外部删除回收站；附件同步；墓碑清单 uuid 并集合并 + 年度保守 GC；sync_state.db（SQLite）；双引擎目录检测 |
| `src/lib.rs` | 新命令：sync_config_get/set、sync_test、sync_now（后台批次）、sync_status、sync_conflict_resolve、sync_history、sync_doc_states；事件：sync:state/progress/conflict/done/error/needs_direction/trashed、sync:moved、doc:external_change |
| `src/library.rs` | rename_doc 拆出可测试内核；open_existing（后台批次重建库）；StartupInfo 增加第三方同步盘警告 |

### 前端（src）

- `api.ts`：同步类型 + 命令门面
- `store.ts`：同步状态机接线；保存后 10s 去抖自动同步（FR-SYN-03）；8 类事件监听；doc:external_change 自动重载（reloadNonce 机制 + 光标/滚动保持桥，A15）；冲突解决三动作
- `components/SyncSettings.vue`：WebDAV 配置（坚果云模板、测试连接、DPAPI 声明、双引擎警告、自动同步开关）
- `components/ConflictView.vue`：双栏只读对比 + 保留此版/保留彼版/手动合并后清理（FR-SYN-04 v1.7 三动作语义）
- `components/DirectionAsk.vue`：首次绑定方向模态（3.3-5 白名单）
- `components/StatusBar.vue`：同步指示（阶段/最近结果/冲突数）+ 同步历史弹层（含传输量）
- `components/TreeList.vue`：逐文档同步标记（待同步 ● / 冲突 ⚠）
- `App.vue`：启动双引擎警告横幅、Ctrl+Shift+S 手动同步
