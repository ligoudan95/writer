4. 加固：replaceRangeWithMd 容错；docx Empty `u val=none`/`b val=off`；撤销到期冲刷排队通知。
5. 确认正确（抽录）：库锁共享注册表、快照迁移五调用点、事件 libRoot 全覆盖（引擎 emit 与手动 tag 双路验证）、BatchGuard、vMerge 网格模拟边界、LIS 主流程（两例手工推演）、notify/store/TreeList/aiflow 主体、NSIS/CSP 取舍定性（NFR-12 明文执行）。

## 记录在案的低风险取舍（不阻塞）

- 排序编号在"空档耗尽"场景下触发锚点也被顺带改号（顺序正确，仅多一次改名）；交换式改名的 `-2` 后缀（显示层短暂）
- docx：嵌套表的 gridSpan/vMerge 会误标外层单元格 span（内容不丢）；`Title`/`Subtitle` 样式落为普通段；hyperlink URL 不导入（文字保留）
- 回收站显示名对"纯数字_"开头原名的解析歧义（还原走 index 不受影响）
- CSP 收紧后 http 图片在编辑器内显示破图（内容保留在 md，Ctrl+点击可打开）——NFR-12 有意取舍；附件本地图片渲染待 assetProtocol 接入（后续项）
- 应用偏好存 localStorage（应用作用域等价）；IPC 分块仅 PDF 管线；NSIS 许可协议页需自定义模板（V1.0 以 LICENSES/ 目录 + 关于页承载）
- 会话位置在草稿活跃期含草稿偏移（接受后恢复位置轻微后移）
- 沿袭挂账：PDF 自检交互桌面复测、真实双机 A15、真实 Provider 联调（需用户环境）
